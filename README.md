# つみき なんこ？

Unity 6 LTSで開発する、4〜6歳向けの積み木計数学習アプリです。

## 開き方

Unity HubからこのフォルダをUnity `6000.0.82f1`で開き、`Assets/Tsumiki/Scenes/Main.unity`を再生します。

## 現在の実装

- 5段階の高さマップ問題生成、連結性、浮遊禁止
- 等角投影に基づく完全隠れ判定
- 上・前・横の三面図データ生成
- 12色ブロックと各立方体の稜線表示
- ホーム、レベル選択、4つの学習モード、設定、保護者向け概要
- 累計解答数の端末保存
- 「くろ」の仮キャラクター素材

## リリース前に必要な外部設定

- 仮Bundle ID `com.hayashiminoru.tsumikinanko` を確定値へ変更
- App Store Connectで非消耗型商品3件を登録
- 正式音声、効果音、BGMの制作・全件試聴
- StoreKit Sandboxで購入、復元、中断復帰を実機確認
- Kidsカテゴリの保護者ゲートとストア文言を審査時点の要件で再確認
